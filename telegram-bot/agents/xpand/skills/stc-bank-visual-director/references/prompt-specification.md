# Final English prompt contract
Return one actionable prompt after style selection, with no generated advertising copy. When useful precede it with one concise Arabic concept explanation outside the prompt.
Order: visible situation and benefit → selected style → dominant hero and supporting action → physical set/supports → one camera setup → composition and quiet space → reference-driven color → light/shadow/reflection/material behavior → output exclusions.
Name the exact reference role: use the primary image for hue/light/surface language, another only for viewpoint or gesture. Never treat an advertisement as an exact product asset. References do not authorize copying typography or logos.
Purple example structure: a meaningful product interaction on connected violet lacquer planes; product axes agree with support plane; elevated oblique view showing top/side; soft key above left, broad violet background illumination, restrained metal reflection, correct attached shadow; dark-to-lit violet values sampled from selected reference; quiet upper-right region. Replace placeholders with the specific benefit, not a universal pedestal scene.
Realistic structure: an observable action in a clean real location, palette drawn from that location, a specific unusual but plausible viewpoint, material clarity and natural contact; no global purple grade.
Surreal structure: a real scene with one clearly named scale/spatial intervention, one shared camera and motivated light; avoid supernatural effects.
Negative tail: no text, letters, numbers, logos, watermark, readable UI, graphic overlays, decorative lines, particles, holograms or unsupported floating elements. Natural structural edges/reflections are permitted.
Do not promise exact offer comprehension without typography. Do not claim a generated blank/unreadable screen shows a verified banking app. User-supplied branded content requires an explicit exception to this project's no-text/no-logo rule.

A standalone prompt must describe hue/value, surface, reflection and camera behavior directly. Never write “inspired by stc_curated_02” or “see reference image 2” without actual attached images in the target request. Reference products do not determine the requested service's product category. Preserve the reviewed winner's benefit proof and main action before adding finish language.
